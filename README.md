# 📚 词汇学习默写工具 (CSV Learning App)

> 🔐 仓库已配置 SSH 连接，推送更稳定！

一个基于 Python + Tkinter 的 CSV 词汇默写学习助手，支持多种 AI 服务商（包括本地 Ollama）进行智能判定对错。

## ✨ 主要功能

- 📖 **CSV 导入学习**：导入自定义的三列 CSV 词汇表进行默写练习
- 🧹 **智能括号清理（可开关）**：自动忽略答案中的括号说明文字（如 `苹果（复数）` 等价于 `苹果`），避免 AI 判定失误；学习页进度栏一键切换
- 💾📂 **进度保存/恢复**：一键保存当前学习进度到 TXT 文件（文件名含时间戳和CSV名），下次打开直接继续学到的位置
- 🤖 **AI 智能判定**：支持 Ollama（本地）、OpenAI、通义千问、智谱 GLM、文心一言等多种 AI 服务商智能判断答案
- ⚙️ **本地算法兜底**：AI 不可用时自动切换到本地文本相似度算法
- 🎯 **多轮复习机制**：错题自动进入错题本，支持反复复习直到全部掌握
- 📊 **学习统计**：实时显示进度、正确率、错误数等学习数据
- 📥 **错题导出**：将错题导出为 CSV 文件，便于后续整理和复习
- ✏️ **手动修正判定**：支持手动标记正确/错误，纠正 AI 误判
- 🔌 **一键安装依赖**：内置依赖库安装按钮，轻松配置环境

## 📝 CSV 文件格式

CSV 文件必须是 **UTF-8 编码**，且至少包含 **3 列**：

| 第一列（单词/问题） | 第二列（词性/提示） | 第三列（标准答案） |
| :--- | :--- | :--- |
| 苹果 | n. | apple |
| 跑 | v. | run;奔跑 |
| 高兴的 | adj. | happy |
| child | n. | child（复数：children）；kid |

> **注意**：
> - 多个标准答案可以用英文分号 `;` 分隔（如 `run;奔跑`），任意一个匹配即为正确。
> - **括号内容会被自动忽略（功能可开关）**：答案中的说明文字（支持 `（）`、`()`、`【】`、`[]`、`{}`、`<>` 六种括号）在判定和显示时会自动清除。例如：
>   ```
>   child（复数：children）；kid    →    等价于 child;kid
>   apple(pl. apples)               →    等价于 apple
>   ```
>   这样用户只要输入 `child` 或 `apple` 即可判对，括号内的备注不会影响 AI 判定。
>   可在「学习页 → 进度信息栏」的复选框一键开启/关闭该功能。

项目中已附带示例文件：
- `vocabulary_learning.csv` — 词汇学习示例
- `example_data.csv` — 简单格式示例

## 🎮 使用说明

### 学习模式

1. 点击「选择 CSV 文件」加载词汇表
2. 应用会依次显示题目（第一列 + 第二列提示）
3. 在答案框中输入答案，按回车或点击「提交答案」
4. AI 或本地算法会自动判定对错，并给出详细分析
5. 完成一轮后可「开始新一轮复习」专攻错题

### 文件操作区（学习页顶部）

| 按钮 | 功能 | 说明 |
| :--- | :--- | :--- |
| 📂 选择 CSV 文件 | 加载词汇表 | UTF-8 编码，至少 3 列 |
| 💾 保存进度 | 保存当前进度到 TXT | 文件名格式：`YYYYMMDD_HHMMSS_CSV名.txt` |
| 📂 读取进度 | 从 TXT 恢复学习 | CSV丢失时可手动重选，保留所有进度和错题 |

**保存的进度文件包含**：保存时间、CSV路径、当前题号、轮次、正确/错误数、错题本全部内容。

### 进度信息栏（学习页第二行）

| 元素 | 说明 |
| :--- | :--- |
| 轮次 | 当前第几轮复习 |
| 进度 | 当前题 / 总题数 |
| 正确·错误 | 答题统计 |
| 🦙 AI 状态 | 显示当前使用的判定方式（Ollama / 本地 / 已禁用） |
| 🧹 忽略括号备注 | **括号清理开关**，点击立即切换并自动保存（开关文字会说明当前状态）；与「设置」页对应开关双向同步 |

> **💡 括号开关状态说明**：
> - ✅ 绿色文字 `🧹 已开启：苹果（复数） → 苹果` → 括号备注不参与判定（推荐）
> - ❌ 灰色文字 `📝 已关闭：苹果（复数）原样参与判定` → 完整答案参与匹配
> - **任一处修改立即同步**：无论在「学习页」还是「设置页」改动，另一边会自动勾选一致。

### 快捷键

- **Enter** — 提交答案
- 其他操作通过界面按钮完成

### 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| ✅ 提交答案 | 提交当前答案并判定 |
| ⏭️ 跳过此题 | 跳过当前题（自动计入错题） |
| 💡 查看答案 | 显示正确答案（不判定） |
| ➡️ 下一题 | 跳过当前题直接下一题 |
| ✅ 标记为正确 | 手动将 AI 判错题改为正确 |
| ❌ 标记为错误 | 手动将 AI 判对题改为错误 |
| 🔄 开始新一轮复习 | 只复习错题 |
| 📥 导出错题本 | 将错题导出为 CSV |
| 🗑️ 重置 | 清空所有数据回到初始状态 |

## 🔧 核心类说明

### `OllamaAILearningAssistant`
AI 判定核心类，负责：
- 多 AI 服务商统一调用接口
- AI 返回结果解析与容错
- API Key、模型选择等配置的加载和保存（`ai_config.json`）
- Ollama 本地运行状态检测与模型列表获取

### `CSVLearningApp`
Tkinter GUI 主类，负责：
- 学习模式界面（加载 CSV、答题、判定显示、进度统计）
- AI 设置界面（服务商选择、Ollama 配置、API Key 管理）
- 错题管理（错题收集、复习轮次、CSV 导出）
- 手动修正判定结果

## 📊 本地判定算法

当 AI 功能禁用或调用失败时，使用 `difflib.SequenceMatcher` 文本相似度算法：

| 相似度 | 判定结果 |
| :--- | :--- |
| 100% | ✨ 完美匹配，完全正确 |
| ≥ 90% | ✅ 基本正确（格式/同义词差异） |
| 70% ~ 89% | ⚠️ 部分正确，需注意差异 |
| 40% ~ 69% | ❌ 相似度较低，建议重学 |
| < 40% | ❌ 差异较大，重新学习 |

## ⚠️ 常见问题

**Q: Ollama 显示未连接？**
A: 先确保已安装 Ollama 并在命令行运行 `ollama serve` 或直接执行 `ollama run qwen2.5:7b`，确认模型可用后再检测。

**Q: CSV 文件加载报错？**
A: 请确保 CSV 为 **UTF-8 编码**，且至少包含 3 列。可用 Excel 或 VS Code 转换编码。

**Q: 多个答案如何填写？**
A: 用英文分号 `;` 分隔，例如：`run;奔跑`。任意一个答案匹配即算正确。

**Q: 答案里想加备注说明（词性、复数等）会影响判定吗？**
A: **默认不会！** 程序会自动清除六种括号 `（）()【】[]{}` `<>` 及其中内容。例如 `苹果（复数：apples）` 在判定时等同于 `苹果`，可以放心给答案加备注。
如果确实需要括号参与判定，可在「学习页进度栏」把 **「🧹 忽略括号备注」** 开关取消勾选（再点击一次即可关闭）。

**Q: 学到一半要关机怎么办？**
A: 点击「💾 保存进度」导出 TXT 文件，下次打开程序点「📂 读取进度」选择之前保存的 TXT，就能从上次的题目继续学习（含轮次、正确/错误数、错题本等全部状态）。

**Q: AI 判定不准确？**
A: 可使用下方的「手动标记为正确/错误」按钮进行修正，或在设置中切换更强大的模型。
